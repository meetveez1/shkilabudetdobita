# Умный поиск по книгам

Веб‑сервис для поиска по книгам (`.txt`) и ответов на вопросы по их содержанию.

## Что реализовано

- Загрузка пользовательских книг в формате `.txt` через веб‑интерфейс.
- Индексация книг на фрагменты (чанки) с сохранением источника: книга + приблизительное место (глава/часть + номер фрагмента).
- Поиск 3–5 наиболее релевантных фрагментов по пользовательскому запросу.
- Режим вопрос‑ответ по книгам с обязательным выводом цитат, на которых основан ответ.
- Честный отказ, если релевантных данных недостаточно.

## Технологический стек

- Python 3.11+
- Flask (веб‑интерфейс)
- SQLite + FTS5 (полнотекстовый поиск)

## Как запустить

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

После запуска сервис доступен на `http://localhost:8000`.

## Как загрузить тексты книг

1. Откройте главную страницу.
2. В блоке **"1) Загрузить книгу (.txt)"** выберите текстовый файл.
3. При желании задайте человекочитаемое название.
4. Нажмите **"Загрузить"**.

Книга разобьётся на фрагменты и станет доступной для поиска/вопросов.

## Примеры работы

### Тестовые книги

- `examples/war_and_peace_excerpt.txt`
- `examples/idiot_excerpt.txt`

### Пример 1: Поиск фрагментов

**Запрос:** `Найди, где говорится про Наташу и бал`

**Ожидаемо:** среди первых результатов есть фрагмент из `war_and_peace_excerpt`, где упоминается, что Наташа появилась на балу.

### Пример 2: Вопрос‑ответ

**Вопрос:** `Что произошло с Наташей и Пьером в эпилоге?`

**Ожидаемо:** ответ о том, что Наташа и Пьер поженились и жили семейной жизнью; ниже приводятся цитаты‑основания из эпилога.

### Пример 3: Честный отказ

**Вопрос:** `Какой университет окончил Пьер?`

**Ожидаемо:** сообщение, что надёжного ответа в загруженных книгах не найдено.

## Архитектура

- `app.py` — Flask‑маршруты и UI.
- `smart_book_search/db.py` — схема БД и инициализация.
- `smart_book_search/ingestion.py` — загрузка книги и разбиение на чанки.
- `smart_book_search/retrieval.py` — поиск релевантных фрагментов через FTS5.
- `smart_book_search/qa.py` — формирование ответа на основе найденных фрагментов.

## Ограничения текущей версии

- Место в тексте определяется по маркерам главы/части и номеру фрагмента, а не по страницам.
- Генерация ответа реализована как extractive QA (выбор релевантных предложений), без внешней LLM.
